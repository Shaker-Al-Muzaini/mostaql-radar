# 02 — تصميم تجربة المستخدم والواجهة (UX/UI)

## مبادئ
1. **المسح السريع أولاً:** أنت تفتح الأداة لتقرر خلال ثوانٍ: هل المشروع يستحق؟ لذلك الدرجة والميزانية وعدد العروض ظاهرة في كل بطاقة.
2. **زر واحد رئيسي:** «تحديث الآن» دائماً ظاهر في الأعلى.
3. **عربي RTL بالكامل:** `dir="rtl"` على مستوى الصفحة، أرقام لاتينية، خط Tajawal.
4. **لا إرسال بدون موافقتك:** كل مسودة تمر بحالة «مسودة» قبل أي شيء.

## خريطة الشاشات
```
┌ الشريط العلوي: الشعار | المشاريع | العروض | [تحديث الآن] ┐
│
├ /           قائمة المشاريع  (فلاتر + بطاقات)
│   └ درج التفاصيل: الوصف، ملخص AI، سبب الدرجة، زر «اكتب عرضاً»
├ /proposals  سجل العروض (جدول + فلتر الحالة + محرر المسودة)
```

## تدفق المستخدم الرئيسي
1. يضغط «تحديث الآن» ← شريط تقدم ← «وُجد 7 مشاريع جديدة».
2. يرشّح بالدرجة ≥ 70 ← يفتح مشروعاً ← يقرأ ملخص AI.
3. «اكتب عرضاً» ← مسودة في محرر ← يعدّل ← «موافقة» ← ينسخ النص ويفتح رابط مستقل لتقديمه.
4. «تم الإرسال» يحفظ العرض في السجل.
(الطريق نفسه ممكن بالكامل من تيليجرام.)

## شاشة قائمة المشاريع
- **الفلاتر (شريط جانبي/علوي):** بحث نصي، التصنيف، أدنى درجة (شريط تمرير)، أدنى ميزانية، الحالة (جديد/تم الاطلاع/مقدَّم/متجاهل)، «إخفاء ما قدمت عليه».
- **البطاقة:** العنوان، شارة الدرجة (أخضر ≥ 80، أصفر 60–79، رمادي أقل)، الميزانية، عدد العروض، الوقت، التصنيف، سطر ملخص AI.
- **حالات:** تحميل (هياكل رمادية)، فارغة («لا مشاريع تطابق الفلاتر»)، خطأ (رسالة + إعادة محاولة).

## شاشة سجل العروض
جدول: المشروع، الحالة (شارة ملونة)، المبلغ، المدة، التاريخ؛ نقر على صف يفتح المحرر. أزرار: موافقة، رفض، تم الإرسال، إعادة توليد.

## نظام التصميم
| العنصر | القيمة |
|---|---|
| الخط | Tajawal (400/500/700) |
| الخلفية | `#f7f7f5` ، البطاقات `#ffffff` |
| النص | `#1a1a1a` ، ثانوي `#6b6b66` |
| اللون الرئيسي | `#0f766e` (تيل) |
| نجاح / تحذير / خطر | `#15803d` / `#b45309` / `#b91c1c` |
| الحواف | 12px للبطاقات، 8px للأزرار |
| المسافات | مضاعفات 4px |

## إمكانية الوصول
تباين لوني ≥ 4.5:1، تركيز لوحة مفاتيح ظاهر، الدرجة تُعرض كرقم ونص لا باللون وحده، أهداف نقر ≥ 40px.

## الاستجابة
هاتف: الفلاتر داخل لوحة قابلة للطي، درج التفاصيل بملء الشاشة. حاسوب: عمودان (فلاتر 280px + قائمة).

## رسائل تيليجرام
```
🎯 مشروع مناسب (92/100)
<العنوان>
💰 25–50$ · 📩 4 عروض · 🏷 برمجة
<ملخص سطرين>
[✍️ اكتب عرضاً] [🔗 افتح] [🙈 تجاهل]
```
المسودة: النص + `[✅ موافقة] [❌ رفض] [🔄 إعادة]`.
